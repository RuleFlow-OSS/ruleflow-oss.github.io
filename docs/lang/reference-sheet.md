# Reference Sheet

!!! abstract ""
    The FlowLang Reference sheet is a concise, quick-lookup guide designed to help you rapidly use FlowLang without constantly referencing the documentation. It condenses the language's core directives, operators, and flags into an easily scannable format. It is in a pdf format for convenient printing and offline access. It is highly recommended to print out a copy when getting started with FlowLang.
