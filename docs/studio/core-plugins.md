# Core Plugins

!!! abstract "Core vs. External Plugins"
    * **Core Plugins** are the essential, built-in tools that ship natively with RuleFlow Studio. They provide the foundational out-of-the-box functionality required to execute, visualize, and analyze complex discrete systems.
    * **External Plugins**, by contrast, are custom extensions developed by researchers or the community to fit highly specific workflows. To install and use an external plugin, you simply drop its Python file directly into your project's designated `plugins` folder, and RuleFlow Studio will dynamically load it into your workspace.

The following are examples of the core plugins included with RuleFlow Studio. This list is not exhaustive, but it highlights the primary tools you will use to interact with your simulated environments.

## Execute Plugin

The Execute plugin manages the lifecycle of your system, providing granular control over the engine's progression, memory, and runtime debugging.

* **Playback & Navigation:** Cleanly execute, stop, regress by specific step counts, or clear the flow's evolution memory entirely using the workspace toolbar.
* **Hot Reloading:** Automatically re-execute the simulation after a configurable number of source code changes, allowing for rapid parameter tuning and instant visual feedback.
* **Program Log & Profiling:** An integrated rich log captures standard output, script errors, and deep tracebacks. Enabling the memory profile tracks the computation time and megabytes consumed during execution.
* **Programmed Flows:** When using bootstrapped scripts (`.pflow` or `.wpflow`), dedicated inputs allow you to pass runtime arguments and keyword arguments directly into the evaluation environment.

## Explore Plugin

The Explore plugin serves as the primary visual and interactive interface for inspecting the state of your spatial vectors across time and multiway branches.

* **Evolution Data Table:** View the evolutions's timeline based on a specific event range. Toggle columns to track granular metrics per step, including Cell Count, Causal Distance, Causally Connected counts, and Destroyed/Created Cells.
* **Hover Explorer:** Hover over individual cells in the data table to reveal their exact Quanta, Generation, and Identity. You can apply persistent highlight styles (e.g., `on green` or `bold blue`) to track specific generations or identities across the entire simulation.
* **Advanced Cell Rendering:** Map distinct visual styles or symbols to specific cells based on their properties. The renderer supports ordered color spectrums, custom base styles, justifications, and specific character overrides to make complex spatial patterns readable.

??? tip "Multiway System Navigation"
    When dealing with overlapping conflicts and branched histories in the Explore plugin, enabling **Ensure Branch Integrity** forces the explorer to walk backward up the multi-way tree nodes based on your current space coordinate. This ensures the temporal relationship between spaces is strictly conserved on your screen.

## Analysis Plugin

The Analysis plugin shifts the focus from physical cell space to the underlying directed acyclic graphs (DAGs) and causal structures generated by the system's evolution.

* **Causal Graph Metrics:** Generates a live data table of the system's topological properties, instantly calculating the Edge-Node Ratio, Network Density, Longest DAG Path, Degree Assortativity Coefficient, and Flow Hierarchy.
* **VisJS Viewer:** Renders the causal network interactively in your browser. It includes extensive canvas controls (backgrounds, fonts, dimensions), hierarchical layout toggles, and UI filters to manipulate nodes, edges, and physics simulations on the fly.
* **Causal Distributions:** Calculates the Min, Max, or Mean of causal data across an event range, visualizing the Causal Distance and Connected Total metrics as embedded terminal sparklines.

??? note "Supported Export Formats"
    You can export the generated causal networks directly to your project path for use in external analytical tools. Supported formats include Gephi (.gexf), GraphML, Sparse6, Graph6, GML, Adjacency List, and Multiline Adjacency.
